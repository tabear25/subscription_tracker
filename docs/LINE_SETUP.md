# LINE通知 セットアップ手順書

このツールでLINE通知を使うために、**あなた自身が行う作業**を順番にまとめたものです。
所要時間の目安は **15〜20分**。難しいプログラミングは不要で、ほとんどが画面上のクリック操作です。

> **重要**: 昔よく使われた「LINE Notify」は **2025年3月31日に終了**しました。
> このツールは現行の **LINE Messaging API（LINE公式アカウント経由のプッシュ配信）** を使います。
> `LINE_CHANNEL_ACCESS_TOKEN` を設定しなければLINE送信は自動でスキップされ、カレンダー通知だけが動きます。

---

## 全体の流れ

```
1. LINE公式アカウントを作る
2. Messaging API を有効にする
3. チャネルアクセストークンを発行する（← これをGASに登録する）
4. 自分のスマホで公式アカウントを友だち追加する
5. GASのスクリプトプロパティにトークンを登録する
6. テスト送信して、自分のLINEに届くか確認する
```

---

## STEP 1. LINE公式アカウントを作る

1. PCブラウザで [LINE Official Account Manager](https://manager.line.biz/) を開く。
2. 自分のLINEアカウントでログインする。
3. 「アカウントを作成」から新しい公式アカウントを作成する（**無料プランでOK**）。
   - アカウント名は何でも構いません（例: `サブスク通知`）。
   - 業種などを聞かれたら、適当に近いものを選んでOKです（個人利用なので影響はありません）。

> 💡 公式アカウント＝「自分専用の通知Bot」だと思ってください。ここから自分のLINEへメッセージが届きます。

---

## STEP 2. Messaging API を有効にする

1. [LINE Developers Console](https://developers.line.biz/console/) を開き、同じLINEアカウントでログインする。
2. 初回はプロバイダー（Provider）の作成を求められます。名前は何でもOK（例: `personal`）。
3. STEP 1で作った公式アカウントが一覧に出てくるので選択する。
   - もし出てこない場合は、LINE Official Account Manager 側の「設定 → Messaging API」から **Messaging APIを利用する** を有効化すると、Developers Console に表示されます。
4. これで「Messaging APIチャネル」が使える状態になります。

---

## STEP 3. チャネルアクセストークンを発行する（最重要）

1. Developers Console で対象チャネルを開き、上部タブの **「Messaging API設定」** をクリック。
2. ページ下部の **「チャネルアクセストークン（長期）」** を探す。
3. **「発行」** ボタンを押すと、長い文字列のトークンが表示されます。
4. このトークンを**コピーして安全な場所に控えておく**。
   - これが後で `LINE_CHANNEL_ACCESS_TOKEN` に入れる値です。

> ⚠️ **取扱注意**: このトークンは「あなたのBotを操作できる鍵」です。
> GitHubやチャット、スクリーンショットなどに**貼り付けて共有しないでください**。
> （万一漏れた場合は、同じ画面で再発行すれば古いトークンは無効化できます。）

---

## STEP 4. 自分のスマホで公式アカウントを友だち追加する

このツールは **broadcast（友だち全員へ配信）** を使うため、配信先として自分が友だちになっている必要があります。

1. 「Messaging API設定」タブにある **QRコード**（Bot basic ID / QRコード）を表示する。
2. スマホのLINEアプリで、そのQRコードを読み取り、**友だち追加**する。

> 💡 個人利用なら「友だち＝自分1人」になるので、broadcastはそのまま自分宛ての通知になります。
> 宛先のユーザーIDを調べる必要はありません。

---

## STEP 5. GASのスクリプトプロパティにトークンを登録する

1. [Google Apps Script](https://script.google.com/) で、このツールのプロジェクトを開く。
2. 左メニューの **⚙️（プロジェクトの設定）** を開く。
3. 「スクリプト プロパティ」に以下を追加する。

   | プロパティ (Key) | 値 (Value) |
   | --- | --- |
   | `LINE_CHANNEL_ACCESS_TOKEN` | STEP 3で控えた長期トークン |

4. 保存する。

> ℹ️ `NOTION_TOKEN` と `DATABASE_ID` が未設定の場合は、先に [README](../README.md) の手順で設定しておいてください。

### （推奨）タイムゾーンの確認
月末リマインドの判定は、GASプロジェクトのタイムゾーンに従います。
`appsscript.json`（プロジェクト設定の「『appsscript.json』マニフェストファイルをエディタで表示する」をオンにすると見えます）の `timeZone` が
`"Asia/Tokyo"` になっていることを確認してください。

---

## STEP 6. テスト送信して動作確認する

1. GASエディタで、関数の選択ドロップダウンから **`testLineNotification`** を選ぶ。
2. **「実行」** を押す。
   - 初回は「承認が必要です」と出るので、自分のGoogleアカウントで承認してください
     （外部サービスへの接続＝LINEへの送信を許可するためです）。
3. 自分のLINEに
   **「【テスト】LINE連携の確認です。これが届いていれば設定は成功です。」**
   が届けば **成功** です 🎉

### 届かないときのチェックリスト
- [ ] STEP 4で自分が公式アカウントを**友だち追加**できているか（ブロックしていないか）
- [ ] `LINE_CHANNEL_ACCESS_TOKEN` の値に余分なスペースや改行が混ざっていないか
- [ ] トークンが「**長期**」のものか（短期トークンや別チャネルのトークンではないか）
- [ ] GASの実行ログ（エディタ下部）に `❌ LINE送信エラー` が出ていないか
  - `401` → トークンが間違っている／無効
  - `403` → 友だち追加されていない、または権限不足

---

## 設定後の動き

設定が完了すると、毎日動く `main` トリガーによって自動的に：

- **支払日の7日前** … 「💸 請求予告」がカレンダー＋LINEに届く
- **毎月末日** … 「先月、新規でサブスクを登録したり料金プランを変更したりしていませんか？」という
  見直しリマインドが、現在の契約状況サマリー付きでLINEに届く

…が行われます。**月末リマインドのために新しいトリガーを追加する必要はありません**
（毎日の `main` 実行の中で「今日が月末か」を判定しています）。

## 困ったときに Claude Code に頼めるプロンプト例

LINE Developers Console などの画面操作は自動化できませんが、確認やコード作成は依頼できます。

- 「`LINE_CHANNEL_ACCESS_TOKEN` を使って broadcast でテスト1通を送る `curl` コマンドを作って」
- 「発行したチャネルアクセストークンが有効か疎通確認するワンショットスクリプトを書いて」
- 「`testLineNotification` をGASで実行する手順を、初めての人向けに教えて」
- 「LINE送信で `401` エラーが出た。原因の切り分け手順を教えて」
