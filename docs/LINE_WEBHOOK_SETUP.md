# LINEで話しかけて確認・操作する（双方向 / Webhook）セットアップ手順書

LINEのトークにふつうの文章を送るだけで、サブスクの**支払日の確認・解約／再契約の案内と記録・一覧・利用記録**ができるようにする設定です。
[LINE_SETUP.md](LINE_SETUP.md) の通知設定（公式アカウント作成・トークン発行・友だち追加）が**先に完了している前提**です。

所要時間の目安は **10〜15分**。ほとんどが画面上のクリック操作です。

> ⚠️ **セキュリティ上の重要な注意**
> Google Apps Script の `doPost` はHTTPヘッダーを読めないため、LINEの署名（`X-Line-Signature`）による正規リクエスト検証が**できません**。
> そのため、解約などの操作は **`ALLOWED_LINE_USER_IDS`（許可ユーザーID）** で保護します（後述）。**必ず設定してください**。
> なお、LINEから変わるのは Notion の Status・更新日・最終利用日だけです（「解約取り消し」で元に戻せます）。各サービスの契約そのものには触れません。

---

## 話しかけ方

公式アカウントのトークに、こんな文章を送ると動作します（決まった書式でなくてOK）。

| 送る言葉の例 | 動作 |
| --- | --- |
| `Netflixっていつ支払いだっけ？` / `ネトフリの次の引き落としは？` | 次回支払日・あと何日・金額を返信 |
| `支払い予定` / `今月の支払い` / `来月いくら？` | 期間内の支払いを日付順に一覧（合計つき） |
| `一覧` / `サブスク全部でいくら？` | 契約中サブスクと月額・年額換算の合計 |
| `Netflix解約したい` / `解約 Netflix` | **解約方法（解約ページ・手順）と期限**を案内。Notionはまだ変えません |
| `Netflix解約した` / `Netflix 解約済み` | Status を `Canceled` にして通知を止める |
| `Netflix再契約したい` / `再開 Netflix` | 再契約ページと「今日再契約した場合の次回支払日」を案内 |
| `Netflix再契約した` | Status を `Active` に戻し、次回支払日（今日から1サイクル後）をセット |
| `Netflix 続ける` / `Netflix 解約取り消し` | 解約リマインドを止める／解約済みにしたのを取り消す |
| `Netflix使った` | 「最終利用日」を今日に記録（未使用検知用） |
| `解約済み一覧` | 解約済みのサブスク（再契約ボタンつき） |
| `ヘルプ` | 使い方を返信 |

- **サービス名**は Notion の Name のほか、一部だけ（`disney` → Disney Plus）、よく使われる呼び名（`ネトフリ`・`アマプラ` など）、Notionの「別名」列に書いた名前でも通じます。複数に当てはまるときは候補をボタンで聞き返します。
- **名前を省いた発言**（`これいつ？`・`解約した`）は、直前に話したサービス（または当日の通知のサービス）として扱います。誤操作を防ぐため、名前なしの「解約した」は直前に「解約したい」の案内をしたときだけ有効です。
- 返信や通知には、タップで送れる**ボタン**（`✅ 解約済みにした`・`📅 支払い予定` など）が付きます。

### 解約は「案内 → 完了の報告」の2段階

各サービス（Netflix など）の解約は、外部から代行できる公開APIが無いため、このツールでは実行できません。
そこで、Notionだけ先に解約済みになって通知が止まり、実際には請求が続く…という事故を防ぐため、次の流れにしています。

1. `Netflix解約したい` → 解約ページのリンク・手順と、**期限の目安（次回支払日の2日前）**を返信（App Store・Google Play・Uber One などは「更新の24〜48時間前まで」が締切のため）
2. リンク先で解約手続きをする
3. `解約した`（またはボタン）→ Notion を `Canceled` にして通知を停止

1 のあと完了の連絡が無いまま支払日が近づくと、**3日前と前日**に「解約手続きはお済みですか？」とLINEで念押しします（`続ける` で止められます）。

解約方法は次の順で案内します。

1. Notionの「解約用URL」「解約方法」列（自分で書いたものが最優先。再契約の案内は「再契約URL」列）
2. 「支払方法」列が App Store / Google Play / キャリアなら、その解約手順（サービスのサイトからは解約できないため）
3. 主要サービスの組み込みの解約ページ・手順（Netflix・YouTube Premium・Spotify・Amazonプライム・Kindle Unlimited・U-NEXT・Disney+・ChatGPT・Claude・Adobe・Microsoft 365・Apple系）
4. Notionの「URL」列（契約管理ページ）
5. どれも無ければ Google 検索のリンク

## STEP 1. ウェブアプリとしてデプロイする

1. [Google Apps Script](https://script.google.com/) でこのツールのプロジェクトを開く。
2. `webhook.js` の内容がプロジェクトに含まれていることを確認する（`main.js` と同じプロジェクトに置く）。
3. 右上の **「デプロイ」→「新しいデプロイ」** をクリック。
4. 「種類の選択」（⚙️）で **「ウェブアプリ」** を選ぶ。
5. 設定を以下のようにする。
   - **説明**: 任意（例: `LINE Webhook`）
   - **次のユーザーとして実行**: **自分**
   - **アクセスできるユーザー**: **全員**
     （LINEのサーバーから匿名でPOSTされるため「全員」にする必要があります）
6. **「デプロイ」** を押し、初回は承認を求められるので自分のGoogleアカウントで承認する。
7. 表示される **ウェブアプリのURL**（`https://script.google.com/macros/s/.../exec`）を控える。

> 💡 コードを修正したら、**「デプロイを管理」→ 既存デプロイの編集（鉛筆）→「バージョン」を「新バージョン」**にして再デプロイしないと反映されません。URLは変わりません。

---

## STEP 2. LINE側にWebhook URLを登録する

1. [LINE Developers Console](https://developers.line.biz/console/) を開き、Messaging APIチャネルを選択する。
2. **「Messaging API設定」** タブを開く。
3. **「Webhook URL」** に STEP 1 で控えたウェブアプリURLを貼り付け、**「更新」**。
4. **「検証」** ボタンを押し、`成功` と表示されればOK（GAS側が200を返します）。
5. **「Webhookの利用」** を **オン** にする。
6. 同じ画面で、**応答メッセージ（自動応答）を無効** にしておく（Bot任せの自動返信と競合しないように）。
   - 「LINE公式アカウント機能」→「応答メッセージ」をオフ、「Webhook」をオンにします。

---

## STEP 3. 許可ユーザーID（自分）を登録する（セキュリティ）

操作を自分だけに限定するため、自分のLINEユーザーIDをスクリプトプロパティに登録します。

### 3-1. 自分のユーザーIDを調べる

最も簡単な方法は、一度Webhookを動かしてログから拾う方法です。

1. STEP 2 まで終わった状態で、公式アカウントのトークに何かメッセージ（例: `ヘルプ`）を送る。
2. GASエディタの **「実行数」（左メニューの時計みたいなアイコン）** または **`doPost` のログ** を確認する。
   - もしくは、`webhook.js` の `handleLineEvent` に一時的に `console.log(userId)` を入れて送信し、ログでIDを確認してもOKです（`U` から始まる33文字程度の文字列）。

### 3-2. スクリプトプロパティに登録する

GASの **⚙️（プロジェクトの設定）→ スクリプト プロパティ** に追加します。

| プロパティ (Key) | 値 (Value) |
| --- | --- |
| `ALLOWED_LINE_USER_IDS` | 自分のユーザーID（複数人で使うならカンマ区切り `Uxxxx,Uyyyy`） |

> ℹ️ 未設定のままだと**誰でも操作できてしまう**ため、必ず設定してください。
> （`LINE_CHANNEL_SECRET` は将来の署名検証用に読み込んでいますが、GASの制約により現状は使用しません。設定は不要です。）

---

## STEP 4. 動作確認

1. 公式アカウントのトークに **`一覧`** と送る。契約中サブスクの一覧が返ってくれば成功です。
2. **`<サービス名> いつ支払い？`** で、次回支払日・あと何日・金額が返ることを確認。
3. **`<サービス名> 解約したい`** で解約方法と期限が返り、Notionは**まだ変わらない**ことを確認。
4. 続けて **`解約した`**（またはボタン）で Status が `Canceled` になることを確認（Notionで確認）。
5. **`<サービス名> 解約取り消し`** で `Active` に戻ることを確認（テストで解約した場合）。

### うまくいかないときのチェックリスト

- [ ] Webhookの **「利用」がオン** になっているか（STEP 2-5）
- [ ] **応答メッセージ（自動応答）がオフ** になっているか（オンだと定型文が返ってBotの返信と混ざる）
- [ ] デプロイの **アクセス権が「全員」** になっているか
- [ ] コード修正後に **「新バージョン」で再デプロイ** したか（**このツールを更新したときも必要**。しないと古い動きのままです）
- [ ] `ALLOWED_LINE_USER_IDS` に入れたIDが**自分のIDと一致**しているか（違うと「許可されていません」と返る）
- [ ] 「見つかりませんでした」と返る → Notionの Name と違う呼び方をしていないか（よく使う呼び方は「別名」列に書くと通じます）

## 補足

- **解約・再契約はNotionの状態だけを変えます。** 実際の決済（課金の停止や再契約の支払い）は各サービス側で行う必要があります。本ツールは、手続きページへの誘導・期限の提示・完了の記録・し忘れのリマインドを担当します。
- **再契約時の次回支払日**は、Billingに基づく推定値（例: 月払いなら今日から1ヶ月後）を入れます。実際の請求日に合わせてNotionで修正してください。
- **無料枠**: LINEの無料枠（月200通）でカウントされるのは通知（broadcast）だけで、**話しかけたときの返信（reply）はカウントされません**。問い合わせは何回しても無料です。
- **ツールが自動で保存する情報**: 解約手続き待ちのサービスはスクリプトプロパティの `PENDING_CANCELS` に、直前に話したサービス（「これ」「それ」用）は `LINE_CONTEXT_<ユーザーID>` / `LINE_CONTEXT_broadcast` に保存されます。手動で設定・編集する必要はありません（消しても動作に支障はなく、リマインドと文脈がリセットされるだけです）。
- **通知のボタン**: `ALLOWED_LINE_USER_IDS` を設定していると、毎日の請求予告・月末リマインドにもボタン（「解約したい」「支払い予定」など）が付きます（Webhook未設定だとボタンを押しても何も起きないため、設定時のみ付けています）。
