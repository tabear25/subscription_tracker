# 次の支払いウィジェット（Android）

Notion で管理しているサブスクの「次の支払い日・金額」「月額換算の合計」「今月の残りの支払額」を、Android のホーム画面に表示するウィジェットです。Material You（壁紙の色に合わせたダイナミックカラー）に対応しています。

データは、このリポジトリの GAS（[`widget.js`](../widget.js) の `doGet`）から取得します。次回支払日の繰り越しと月額換算は GAS 側で LINE と同じ関数を使って計算するので、LINE の回答と数字がそろいます。

## 表示内容

| サイズ | 表示するもの |
| --- | --- |
| 2×1 | 直近の支払い1件（サービス名・金額・日付・あと何日） |
| 2×2 | 直近の1件、月額換算、今月の残り |
| 4×2（置いたときの既定） | 見出しと更新ボタン、直近の1件、2つの合計、続く2件 |
| 4×3 以上 | 見出しと更新ボタン、直近の1件、2つの合計（タイル表示）、続く4件 |

* **月額換算**: 年払いは12、3ヶ月ごとは3で割って足した合計です。月末の LINE サマリーの「月額換算合計」と同じ値です。
* **今月の残り**: 今日から月末までに支払う分の合計です。LINE の「今月の支払い」と同じ値です。金額が未登録のサービスは 0 円として扱います。
* **タップ**: 更新ボタンを押すと、最新のデータを取り直します。それ以外の場所をタップすると Notion のデータベースが開きます。接続先が未設定のときは設定画面が開きます。
* **自動更新**: 約3時間ごとに取得し直します（WorkManager の都合で時刻は前後します）。取得に失敗したときは前回のデータを表示したまま、見出しに「何時時点のデータか」を表示します。

## 必要なもの

* Android 12 以上の端末（Pixel を想定）
* GAS に `widget.js` を追加し、スクリプトプロパティ `WIDGET_TOKEN` を設定してウェブアプリをデプロイしたもの（手順は[リポジトリの README](../README.md) の「ホーム画面ウィジェットの設定」）
* ビルドする PC に JDK 17 と Android SDK（API 36）

## ビルド

```bash
cd android
# JDK 17 以上の場所を JAVA_HOME に指定する
export JAVA_HOME="/path/to/jdk-17"
./gradlew testDebugUnitTest assembleDebug
```

APK は `app/build/outputs/apk/debug/app-debug.apk` にできます。Android SDK の場所は `local.properties` の `sdk.dir` で指定します（git 管理外）。

> デバッグ用の署名で作った APK です。あとで更新版を入れるときも、同じ PC（同じ `~/.android/debug.keystore`）でビルドしてください。別の署名の APK は上書きインストールできません。

## インストールと設定

1. `app-debug.apk` を Google ドライブなどでスマホに送り、ファイルを開いてインストールします。「この提供元のアプリを許可」を求められたらオンにします。
2. アプリ「サブスク」を開き、GAS のウェブアプリの URL（`https://script.google.com/macros/s/…/exec`）と合言葉（`WIDGET_TOKEN`）を入力して「保存して取得」を押します。「取得できました」と出れば接続できています。
3. ホーム画面の何もないところを長押しし、「ウィジェット」→「サブスク」→「次の支払い」を選んでホーム画面に置きます。

接続先はあとから、アプリアイコン、またはウィジェットの長押し →「ウィジェットを設定」で変更できます。

## 構成

| ファイル | 役割 |
| --- | --- |
| `data/SubscriptionApi.kt` | GAS からデータを取得し、失敗の理由を日本語にする |
| `data/Snapshot.kt` | GAS の応答（JSON）を読む |
| `data/WidgetStore.kt` | 接続先と、最後に取得できたデータを端末内に保存する |
| `widget/WidgetModel.kt` | 保存したデータと今日の日付から、表示する文字を作る（単体テストあり） |
| `widget/NextPaymentWidget.kt` | ウィジェットの見た目（Jetpack Glance） |
| `widget/RefreshAction.kt`、`work/RefreshWorker.kt` | 更新ボタンと定期更新 |
| `settings/SettingsActivity.kt` | 接続先の設定画面（Jetpack Compose・Material 3） |

## セキュリティ

* 合言葉はアプリ専用の保存領域に入れ、Google のバックアップには載せません（`allowBackup="false"`）。
* GAS の URL と合言葉を知っている人は、契約中のサブスクの名前・金額・支払日を読めます（書き換えはできません）。漏れた疑いがあるときは GAS の `WIDGET_TOKEN` を変更し、アプリの設定も新しい合言葉に直してください。
